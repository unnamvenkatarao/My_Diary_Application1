# 📘 My Diary Application

## 📌 Project Overview

**My Diary Application** is a secure, user-friendly full-stack web application developed using Java and Spring Boot for the backend and React.js for the frontend. It allows users to register, log in, and manage their personal diary entries with full CRUD functionality. The app features a clean UI, encrypted user data handling, and a responsive design.

---

## 🧰 Tech Stack

- **Backend:** Java, Spring Boot  
- **Frontend:** React JS, HTML, CSS, JavaScript  
- **Database:** MySQL  
- **IDE:** Eclipse  
- **Build Tool:** Maven  

---

## ✨ Features / Operations

1. 🔐 **User Registration**  
2. 🔓 **User Login**  
3. 📝 **Add Entry**  
4. 📖 **View Entries**  
5. ✏️ **Update Entry**  
6. ❌ **Delete Entry**  
7. 🚪 **Sign Out**

---

## 🚀 How to Run the Project

### ✅ Backend (Spring Boot)
1. Open the project in **Eclipse**.  
2. Configure your MySQL connection in `application.properties`.  
3. Run the project using `SpringBootApplication`.  
4. Backend APIs will be available at `http://localhost:8080`.
